# LLVQ / Leech 格 2-bit 量化 — 评估后决定不复现

**论文**：[Unfolding the Leech Lattice: Fused Multi-Shell Decoding and VRAM Layouts for 2-Bit LLM Weights](https://arxiv.org/abs/2609.02652)
（arXiv 2609.02652，Pier-Jean Malandrino / Scub，2026-09-02，preprint，明确标注 not peer reviewed，21 页）

**结论：方法不实用——精度代价过大、硬件依赖极强、且在自己的对比表里输给 QTIP。
但论文的方法论值得单独学习，见下。**

## 论文做了什么

首个 Λ₂₄(12) 多壳解码器实现（301 类码本）。把码本在载入时转码成四种 GPU 常驻格式
（Slot32 / Planes14 / Planes12x / Golay70），用位移、掩码和谓词查表实现无分支的
融合 dequant-GEMV kernel，避免在推理时解 47 位组合索引。

L40S 上 Planes14 达到字节上界的 65%，相对 FP16 2.15×；端到端 4B–14B 提升 1.11–1.41×。

## 不做的理由

1. **精度代价无法接受。** 4B 模型上 perplexity ×1.384，**MMLU 掉 14.7 个点**。
   论文自陈原因未明：*"the leading untested suspect is calibration composition, not volume."*

2. **在自己的对比里输给已有方案。** 论文贡献 C3 直接承认 QTIP 2-bit kernel
   读少 2.40× 字节且快 2.27×。

3. **硬件依赖极强，换卡即失效。** L40S（带宽受限）上有效；A100 上
   *"every lattice arm falls below FP16"*，因为瓶颈从访存变成指令发射。

4. **没进生产引擎。** 集成的是 Candle 0.9.2（HF 的 Rust 框架），非 vLLM / SGLang。

5. **目标场景没测。** 论文原文：*"The 70B class, **the regime the memory argument
   targets**, is measurable...and **not measured here**."* 只测了 batch 1、
   无 prefill GEMM、三个尺寸且明说 "no scaling law"。

## 但这篇的方法论值得学

作者是单人、无同行评审，工程严谨度却高于本仓库评估过的所有论文。三点可直接借鉴：

**1. 拒绝跨推理栈相除。**

> "the two f16 controls differ (83.09 against our 43.5 tok/s), so the two within-stack
> ratios are reported side by side and **never divided**."

他自建栈的 FP16 基线是 43.5 tok/s，vLLM 0.26.0 是 83.09——自己的栈慢近一倍，
他主动披露，并拒绝拿自己的加速比去和生产栈的数字做除法。

对照 hLLM 那篇用被自己数据证伪的配置当分母报出 64×，同样的诱惑，两种选择。

**2. 表格与数据绑定校验。**

> "make in paper/ **rejects a table that drifts from its CSV**"

论文每个表都和 CSV 绑定，数字漂移则构建失败。

**3. Limitations 毫不掩饰。** batch 1 only、无 prefill GEMM、明说无 scaling law、
MMLU 掉点原因未明、32B 差 1024 字节 shared memory、载入期 transcoding 每进程重复付出、
Golay70 变体低于可用阈值。

**代码开源**：https://github.com/pjmalandrino/llvq （MIT / Apache-2.0），
含全部表格背后的 CSV 与论文源码。4B 量化产物在 HuggingFace，8B/14B 因标定方差未发布。

## 可以直接带走的知识点

**VRAM rate 与 on-disk rate 是两个不同的设计轴。** 2-bit 存储不等于 2-bit 显存占用；
本文的 unfolded layout 实际为 3.59–5.51 b/weight。评估量化方案时须分开看这两个数。

**量化 kernel 的收益会随硬件翻转。** 同一方法在带宽受限的 L40S 上 2.15×，
在带宽更高的 A100 上全线低于 FP16——瓶颈从访存变为指令发射。
量化论文只报单张卡的数字时应保持警惕。
